## Launch Geometry

- One-dimensional launches are common for vectors and reductions.
- Two-dimensional launches are common for images, matrices, and textures.
- Three-dimensional launches are common for volumes and grids.
- Some samples use grid-stride loops so each thread processes multiple elements.

## Mistakes To Notice

- Missing bounds checks on rounded-up grids.
- Mixing byte counts and element counts.
- Assuming `threadIdx.x` is globally unique.
- Writing to an index that multiple threads can reach without atomics or reduction logic.

## Reading Checklist

- Identify which side owns each allocation: host, device, managed, pinned, mapped, or external.
- Find the first transfer or mapping that makes data visible to the GPU.
- Find the kernel launch or library call that performs device work.
- Find the synchronization point that makes results safe to read on the host.
- Ask whether the sample is teaching correctness, interoperability, or performance.
